    feat(ai_util.dart): add AiUtil class to handle text generation using Google Generative AI
    
    The `AiUtil` class is added to handle text generation using the Google Generative AI. This class provides a method `generateText` that takes input examples and an input prompt and generates text based on the examples and prompt.
    
    The `generateText` method constructs a prompt string with input examples using the few-shot prompt technique. It then creates a `GenerativeModel` instance with the AI model name and API key obtained from the `.env` file. The `GenerativeModel` is configured with safety settings and generation parameters.
    
    The `generateContent` method of the `GenerativeModel` is called to generate text based on the prompt. The generated text is returned as the result.
    
    The `AiUtil` class is used in multiple files:
    - `product_service.dart`: The `_generatedProductInventions` and `_generatedProductDetail` methods now use `AiUtil.generateText` instead of `PaLMUtil.generateTextFormPaLM`.
    - `quizz_service.dart`: The `_generativeAIQuizzCoffeJourney` method now uses `AiUtil.generateText` instead of `PaLMUtil.generateTextFormPaLM`.
    - `loading_indicator.dart`: The loading text is updated to indicate that it is loading by using `AiUtil.info`.
    
    The `PaLMUtil` class is marked as deprecated with a deprecation message indicating that it should be replaced with the `AiUtil` class after migration to the Gemini model.
